# Student Management System

## Overview

Student Management System is a console-based Python application used to manage student records. The system allows users to add, view, search, update, and delete student information through a simple menu-driven interface.

## Features

* Add Student Record
* View Student Records
* Search Student by ID
* Update Student Information
* Delete Student Record
* Input Validation
* Menu-Driven Interface

## Technologies Used

* Python 3.x
* Visual Studio Code
* Git & GitHub

## Concepts Used

* Variables and Data Types
* Conditional Statements
* Loops
* Functions
* Lists
* Dictionaries
* CRUD Operations
* Input Validation

## How to Run

  bash
python student_management.py
